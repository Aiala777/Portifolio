# Portfólio — Arthur Aiala

Versão reformulada do portfólio pessoal, feita com HTML, CSS e JavaScript puro para continuar compatível com GitHub Pages.

## Estrutura

```text
portfolio_arthur_aiala/
├── index.html
├── assets/
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── script.js
└── README.md
```

## Como testar localmente

1. Baixe e extraia o ZIP.
2. Abra `index.html` no navegador ou use a extensão Live Server no VS Code.
3. Confira os links de contato e os cards de projetos.

## Como publicar no repositório atual

1. Faça download ou clone do repositório `Aiala777/SITE_portifolio` para ter uma cópia de segurança.
2. Copie `index.html` e a pasta `assets` para a raiz do repositório.
3. Preserve a pasta `images` existente, pois o site antigo pode conter fotos que você queira reutilizar. Esta versão usa um avatar tipográfico e não depende das imagens antigas.
4. Faça commit e push para a branch `master` (ou a branch configurada em Settings → Pages).
5. Aguarde o GitHub Pages publicar e teste o site em desktop e celular.

## Antes de publicar

- Confirme se os textos e tecnologias representam corretamente sua experiência atual.
- Substitua os links genéricos de projetos pelos repositórios públicos corretos.
- Adicione um currículo PDF apenas se quiser disponibilizá-lo publicamente.
- Não publique telas, dados, códigos ou informações confidenciais da empresa.
- O formulário de contato não foi incluído; o botão de e-mail usa `mailto:`.

## Personalização

- Cores e layout: `assets/css/style.css`
- Conteúdo, seções e links: `index.html`
- Menu mobile e ano automático: `assets/js/script.js`


## Personalizar sua foto

Crie a pasta `assets/images/` e coloque sua foto nela com o nome `foto-arthur.jpg`.
Prefira uma foto bem iluminada, com fundo simples e enquadramento do rosto e ombros.
Se a foto não estiver presente, o site mantém as iniciais “AA” como alternativa.

## Fundo animado

A seção inicial possui uma animação leve de pontos e conexões. Ela é decorativa, não depende de bibliotecas externas e é desativada para visitantes que configuraram o sistema para reduzir movimento.
